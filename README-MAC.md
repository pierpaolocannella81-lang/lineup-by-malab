# LineUp by MALab per Mac

Questa cartella contiene il progetto aggiornato di LineUp by MALab per macOS.

Su un Mac, apri il Terminale nella cartella del progetto e usa:

```bash
npm install
npm run mac
```

Al termine, nella cartella `dist` troverai il file `.dmg` da aprire e installare. Per generarlo automaticamente da GitHub, usa l'azione **Crea app macOS**.

Per provare subito il programma senza creare il file di installazione:

```bash
npm start
```

## Windows

Su Windows, nella stessa cartella, usa:

```powershell
npm install
npm run windows
```

Nella cartella `dist` troverai il file di installazione `.exe` e la versione portatile.
